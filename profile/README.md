# InFlow

InFlow is transaction infrastructure for agents. It gives agents the tools to onboard with services, access protected
resources, and pay through agent-native payment protocols.

## Public repositories

- [`inflow-cli`](https://github.com/inflowpayai/inflow-cli) — command-line application and Model Context Protocol
  server for agent onboarding, access, and payments.
- [`inflow-node`](https://github.com/inflowpayai/inflow-node) — TypeScript and Node.js software development kits for
  integrating InFlow, Machine Payments Protocol, and x402.
- [`homebrew-tap`](https://github.com/inflowpayai/homebrew-tap) — Homebrew distribution for the InFlow command-line
  application.

Learn more at [inflowpay.ai](https://www.inflowpay.ai).
