# Support

## Defects and feature proposals

Open an issue in the repository that owns the affected behavior:

- [InFlow CLI](https://github.com/inflowpayai/inflow-cli/issues)
- [InFlow Node.js SDKs](https://github.com/inflowpayai/inflow-node/issues)
- [InFlow Go SDK](https://github.com/inflowpayai/inflow-go/issues)
- [InFlow Python SDK](https://github.com/inflowpayai/inflow-python/issues)
- [InFlow Rust SDK](https://github.com/inflowpayai/inflow-rust/issues)
- [Shared SDK contracts](https://github.com/inflowpayai/inflow-specs/issues)
- [InFlow Homebrew tap](https://github.com/inflowpayai/homebrew-tap/issues)
- [InFlow MCP server](https://github.com/inflowpayai/inflow-mcp/issues)

Include a minimal reproduction, the affected version, and the expected behavior.

## Product and account support

For private product, account, or integration support, email [support@inflowpay.ai](mailto:support@inflowpay.ai).

## Security vulnerabilities

Do not open a public issue. Follow the `SECURITY.md` instructions in the affected repository or email [security@inflowpay.ai](mailto:security@inflowpay.ai).
